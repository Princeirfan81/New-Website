# Rare Wear Website

A self-contained, mobile-friendly custom printing website for Rare Wear.

## Included
- Homepage with your supplied logo and banner
- Products: T-shirts, mugs, bottles, tiles, caps and more
- Product category filters
- WhatsApp order/enquiry buttons
- Custom order form that opens WhatsApp
- Address, phone and Instagram details
- Admin Panel at `admin.html`
- Edit business details
- Replace homepage banner
- Add / edit / delete products
- Change product prices
- Change product photos
- Export / import website data backup
- Responsive mobile design

## Admin
Open `admin.html`.
Default password: `rare123`

Change the password from the Admin Panel after logging in.

## Important
This package is designed as a simple static website. Admin edits are stored in the browser's localStorage, so they are not a secure server-side CMS. For a production site where edits must be available from every device, the next step is connecting the admin panel to a database/backend.

## Local use
Open `index.html` in a browser. If your browser blocks some local file features, run a simple local server from this folder, for example:

Python:
`python -m http.server 8000`

Then open:
`http://localhost:8000`

## Hosting
Upload the contents of this folder to a static host such as GitHub Pages, Netlify, Vercel or your normal hosting provider. For a real multi-device admin system, use a backend/database instead of localStorage.
